# 사용자 평가 설문 (구글 폼 연결)

> 현재 연결된 폼: `청년 경제생활 시뮬레이터 사용자 평가` (2026-11-13 게시, 링크가 있는 누구나 응답, 이메일 수집 안 함).
> 응답 확인과 받기 중지는 폼 소유자 계정의 구글 폼 **응답** 탭에서 합니다. 아래 1~3절은 폼을 새로 만들 때만 필요합니다.

앱의 `#/survey` 화면에서 답하면, 답이 채워진 구글 폼이 새 창으로 열리고 응답자가 거기서 **제출**합니다.
앱은 답을 저장하거나 보내지 않습니다. 응답은 구글 폼(연결한 구글 시트)에만 쌓입니다.

문항 원본은 `frontend/src/survey-config.ts`입니다. 폼의 문항·보기 글자는 아래와 **한 글자도 다르지 않게** 만들어야 미리 채우기가 됩니다.

## 1. 구글 폼 만들기

1. https://forms.google.com 에서 새 양식을 만듭니다. 제목 예: `청년 경제생활 시뮬레이터 사용자 평가`
2. 설정 → 응답 → **이메일 주소 수집: 수집 안함**, **응답 1회로 제한: 끄기**(로그인을 요구하지 않도록).
3. 아래 10개 문항을 순서대로 만듭니다. 1~9번은 **필수**로 켭니다.

| 번호 | 문항 (그대로 붙여 넣기) | 유형 | 보기 |
|---|---|---|---|
| 1 | 연령대 | 객관식 | 19세 이하 / 20~24세 / 25~29세 / 30~34세 / 35세 이상 |
| 2 | 현재 상태 | 객관식 | 학생 / 근로 중 / 구직 중 / 기타 |
| 3 | 이 서비스를 쓰기 전, 나에게 맞는 청년 지원사업을 스스로 찾을 수 있다고 느꼈다. | 선형 배율 1~5 | 1: 전혀 아니다, 5: 매우 그렇다 |
| 4 | 이 서비스를 쓴 뒤, 나에게 맞는 청년 지원사업을 스스로 찾을 수 있다고 느낀다. | 선형 배율 1~5 | 1: 전혀 아니다, 5: 매우 그렇다 |
| 5 | 지원사업 조건이 나와 맞는지, 맞지 않으면 무엇이 다른지 이해하기 쉬웠다. | 선형 배율 1~5 | 1: 전혀 아니다, 5: 매우 그렇다 |
| 6 | 결과를 보고 실제로 신청하거나 더 알아볼 생각이 생겼다. | 선형 배율 1~5 | 1: 전혀 아니다, 5: 매우 그렇다 |
| 7 | 이번에 처음 알게 된 지원사업이나 금융상품이 있었다. | 객관식 | 있었다 / 없었다 |
| 8 | 신청 마감일 캘린더 저장 기능은 어땠나요? | 객관식 | 유용했다 / 보통이다 / 별로였다 / 사용하지 않았다 |
| 9 | 가장 도움이 된 기능 | 객관식 | 지원사업 찾기 / 조건 차이 안내 / 마감일 캘린더 / 생활비 계산 / 적금·예금 찾기 |
| 10 | 불편했던 점이나 바라는 점 (선택, 이름·연락처 등 개인정보는 적지 마세요) | 장문형 | (필수 아님) |

10번 자유 의견은 개인정보가 섞일 수 있어 링크로 넘기지 않고, 응답자가 폼에서 직접 적습니다.

## 2. 미리 채우기 링크 받기

1. 폼 편집 화면 오른쪽 위 **⋮ → 미리 채워진 링크 가져오기**.
2. 1~9번에 아무 답이나 고르고 **링크 가져오기 → 링크 복사**.
3. 복사한 링크(`https://docs.google.com/forms/d/e/.../viewform?usp=pp_url&entry.123...`)를 Claude에게 전달합니다.
   링크에는 문항 번호(`entry.숫자`)만 들어 있고 개인정보는 없습니다.

## 3. 앱에 연결 (Claude 또는 팀원이 수행)

`frontend/src/survey-config.ts`의 `SURVEY_FORM`에 넣습니다.

```ts
export const SURVEY_FORM = {
  formUrl: 'https://docs.google.com/forms/d/e/<폼ID>/viewform',
  entries: { age:'entry.…', status:'entry.…', before:'entry.…', after:'entry.…', learned:'entry.…',
             understand:'entry.…', intent:'entry.…', deadline:'entry.…', best:'entry.…' },
};
```

`entry` 번호는 미리 채우기 링크에 나온 순서가 폼 문항 순서(1~9번)입니다. 문항 id와 짝이 맞는지 확인하세요.
연결 전에는 설문 화면에 "구글 폼 연결 전 · 제출 불가"가 표시되고 제출 버튼이 열리지 않습니다.

## 4. 결과 보기

폼의 **응답 → 스프레드시트에 연결**로 구글 시트를 만들고 팀원과 공유합니다.
발표 때 볼 만한 값:

- 3번(사용 전)과 4번(사용 후) 점수 차이: 같은 사람의 전후 비교(회고식 응답이라는 한계를 함께 적기)
- 5번(조건 이해), 6번(신청·탐색 의향): 11주차 보고서의 "조건 판단의 어려움", "알아도 신청하지 않음"과 연결
- 7번 "있었다" 비율: 정보를 몰랐던 문제와 연결

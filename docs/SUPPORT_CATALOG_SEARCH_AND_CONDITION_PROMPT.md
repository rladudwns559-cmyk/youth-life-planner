# 지원사업 목록 검색과 빈 조건 입력 안내

공개 v19 · 2026-11-01

- 청년지원사업 보기의 분야별 목록 상단에 사업·지원내용 검색창을 추가했다. 사업명·지역·지원내용·별칭을 공백으로 나눠 함께 검색한다.
- 검색은 기존 지역·분야·모집·개인 조건과 함께 적용된다. 검색어 지우기는 다른 조건을 유지한다. 검색어 변경·지우기는 표시 개수를 첫 페이지로 되돌린다.
- 내 조건으로 찾기와 추천 결과 열기는 지역·나이·취업·월세 모두 비어 있으면 결과 대신 안내창을 띄운다. 한 가지 이상 입력하면 나머지 UNKNOWN을 유지한 채 찾을 수 있다.
- 검색어와 모집 필터만 바꾸는 것은 개인 조건 입력으로 간주하지 않는다. 전체 사업 목록은 조건 없이 탐색 가능하다.
- 안내창 닫기·Escape·초점 복구를 지원하고, 조건 입력하기는 지역 선택으로 이동한다.

## 검증

Frontend 374 passed. 작업자 2개로 전체 회귀를 실행했다. TypeScript 및 Vite 공개 빌드 성공.
최초 실행의 안내 컴포넌트 import 누락을 수정했다. 이후 과도한 병렬 실행에서 기존 테스트의 시간 초과를 관측해 동일 시간 제한·작업자 2개로 재실행했다. 최초 실패 로그와 병렬 실행 로그는 output/support-search에 보관했다.
Backend는 변경하지 않았으며 이번 작업에서 재실행하지 않았다. 정책 데이터·금액 계산 변경 없음.

# 기존 서비스와 비교한 보완점 (2026-11-08)

비교 대상은 청년 정책 탐색의 대표 서비스인 **온통청년**, 예·적금 비교의 대표 서비스인 **금융상품한눈에**(금융감독원), 그리고 대표 정책 적금인 **청년미래적금**의 공식 안내다. 표의 "확인" 칸은 2026-11-08에 공식 화면을 직접 열어 본 것이고, "미확인"은 블로그·기사 수준이라 근거가 약하다는 뜻이다.

## 이 프로젝트가 앞서는 점

1. **"확정이 아니다"를 구조로 보여 준다.** 소득·재산처럼 확인하지 못한 조건은 UNKNOWN으로 남기고 신청 가능하다고 말하지 않는다. 제가 연 두 공식 서비스의 목록 화면(정책 검색 목록, 적금 목록)에서는 이런 충족/추가 확인 구분이 보이지 않았다(확인한 범위는 목록 화면까지이고, 개별 상세 화면은 열어 보지 않았다).
2. **기한 있는 근거.** 모든 금리와 모집 상태에 확인일이 붙고, 7일이 지나면 추천에서 빠지거나 "재확인 필요"로 바뀐다.
3. **청년 정책과 금융상품이 한 곳에 있다.** 정책 탐색은 온통청년, 상품 비교는 금융상품한눈에로 나뉘어 있다.
4. 로그인·개인정보 저장 없이 쓴다.

## 이번에 한 것: 정책 통장 10개 공개

- **무엇**: 청년미래적금, 청년내일저축계좌, 청년 주택드림 청약통장과 지역 청년통장 7개를 상품 찾기 화면에 추가했다. 상단의 "정부·지자체 지원 통장 10개 보기" 버튼으로 이동한다.
- **상태 표시**: Python(`tools/build_asset_programs_public.py`)이 향후 45일의 날짜별 상태 표를 미리 만들고, 화면은 오늘 행을 읽기만 한다. 확인일이 7일을 넘으면 "최신 공고 재확인 필요"로 바뀐다. 표 범위 밖의 날짜(예: 이 화면을 오래 방치)에서는 모집 중으로 보이지 않는다.
- **확인한 사실**: 청년미래적금은 금융위원회 보도자료(2026-09-30)를 직접 읽어 일정과 조건이 카탈로그와 일치함을 확인했다(2차 신청 10/7~16, 심사 10/19~11/13, 계좌개설 11/16~27). KB국민은행 주택드림 안내 페이지도 읽었다(소득 기준은 총급여 5천만원 이하로 표시되며, 10월에 보도된 소득요건 완화가 시행됐는지는 이 페이지만으로 판단할 수 없다).
- **원문이 바뀐 출처**: 12개 출처 중 6개의 원문 해시가 10/30 이후 달라졌다. 직접 읽은 2개(청년미래적금, KB 주택드림)는 변화가 부가 영역(인기 뉴스, 기준일 표시)임을 확인했다. 나머지 서울·부산·대전·경기는 읽지 않았으므로 "공식 원문 변경이 감지되어 재검토가 필요"로 표시한다. 청년미래적금을 뺀 나머지 9개 사업은 확인일이 10/30 그대로라 "마지막 확인 이후 시간이 지나 재확인이 필요해요"가 붙는다.
- **하지 않은 것**: 지원금 계산, 예상 수령액, 신청 가능 판정. 카드는 "신청 마감"과 "확인할 조건"만 보여 준다.
- **금리 표기 (2026-11-08 추가)**: 청년미래적금 카드에 "3년 고정금리 · 기본 연 5% · 우대 최대 2~3%"를 표시한다. 공식 보도자료를 읽은 날짜의 값이며, 카탈로그 형식은 바꾸지 않고 `data/asset-programs/rates-20261108.json`을 빌더가 공개 자료에 붙인다(카탈로그 모델을 바꾸면 사업 변경 감지용 해시가 전부 달라지기 때문). 기본금리와 우대금리는 분리하고, 같은 보도자료의 "실질 가입효과 13.2~19.4%"는 정부기여금·비과세를 환산한 수치라 금리가 아니므로 싣지 않았다. 정부기여금·비과세는 합산하지 않고 만기 수령액도 계산하지 않는다. 금리 값은 출처를 해당 날짜에 읽은 경우에만 빌더가 받아들인다.
- **금리를 싣지 않은 것**: 청년 주택드림 청약통장은 KB 페이지가 "우대금리 포함 연 3.1~4.5%(24개월 기준), 정부고시 변동금리"로 표시하는데 기본과 우대가 한 범위로 섞여 있고 변동금리라 기본금리로 구분해 적을 수 없어 뺐다. 지역 통장 7개와 청년내일저축계좌는 카탈로그에 금리 정보가 없고, 이번에 해당 공식 안내의 금리 표기를 읽어 확인하지 않아 싣지 않았다.

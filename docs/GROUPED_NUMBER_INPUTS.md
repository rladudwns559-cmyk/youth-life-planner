# 숫자 입력 천 단위 쉼표와 원본 계산값 보존

공개 v20 · 2026-11-01

공통 GroupedInput을 생활비 입력, What-if, 합성 적금, 실제 상품 비교, 상품 찾기, FinderDialog, 지원사업 검색과 상품 검색에 적용했다.
화면 3000000→3,000,000 / 300000000→300,000,000. 원본 React 상태는 쉼표 없는 문자열이고 기존 검증·계산·API payload를 유지한다.
나이 및 기간은 기존 범위와 정수 조건 유지. 금리 소수점, 빈칸, 0, 음수·과학표기 등 기존 검증 대상 문자를 임의 유효 금액으로 고치지 않는다. 숫자로만 된 검색어는 쉼표 표시, 일반 한글·혼합 검색문은 그대로 유지한다.
그룹 구분자 앞뒤 삭제와 중간 입력·붙여넣기 시 논리적 커서 위치를 유지한다.

## 검증

공통 입력 6개 테스트: 정밀도 보존, 3백만/3억원, 문자 단위 입력, 쉼표 포함 붙여넣기, 전체 지우기, 쉼표 경계 Backspace/Delete, 중간 편집, 검색 숫자/한글, 유효하지 않은 소수/과학표기 보존.
Frontend 380 passed (30개 파일), maxWorkers=2. TypeScript 및 Vite 빌드 성공.
기존 화면 표시 기대값만 그룹 형식으로 바꾸었다. 기존 쉼표 거부 사례 5개는 허용 요구사항과 충돌하므로 밑줄 구분자 거부 사례로 대체했다. 기존 API 전송 숫자와 계산 기대값은 유지했다.
갱신 전 쉼표 거부 테스트의 최초 실패 로그를 previous-comma-rejection.log로 보존했다.
Backend는 수정하거나 이번 작업에서 재실행하지 않았다.

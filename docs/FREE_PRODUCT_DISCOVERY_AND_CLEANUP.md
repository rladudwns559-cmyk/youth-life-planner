## 무료 운영과 자동 갱신 판단

공개 상품 조건 비교는 **상시 Python 서버가 없어도 작동한다.** Python의 전용 비교 함수가 공식 조건의 금액 경계·1~120개월을 미리 계산한 정적 비교표를 만든다. 브라우저는 해당 표를 조회하고 검색/표시만 담당한다. Python 판정·계산 코드를 JavaScript 정책 엔진으로 이식하지 않았다. 예산 계산·정책판정·이자 계산은 계속 기존 Python의 책임이다. 새 HTTP adapter는 로컬 Python에서도 같은 비교를 제공하지만 공개본은 입력을 서버에 전송하지 않는다.

자동 수집·기기 알림은 이번에 보류했다. 무료 예약 실행 수단 자체가 불가능하다고 판단한 것이 아니다. [GitHub Actions 공식 과금 안내](https://docs.github.com/en/billing/concepts/product-billing/github-actions)는 공개 저장소의 표준 runner 무료 범위와 private 한도를 설명한다. 그러나 현재 연결된 공개 Site에는 검증된 무인 수집 writer/개인 구독 저장소/클라우드 push 실행 경로가 없다. 무료라는 이유만으로 새 계정·키·자동작업을 생성하거나 동작한다고 표시하지 않았다. 사용자 허용 fallback에 따라 상품 탐색을 우선 완성했다. Site automation 조회는 빈 목록이며 새 schedule0건이다.

Render·유료 서버·디스크·이메일 발송서비스 신청0건, 새 요금제0건, 추가 LLM실행0회. 기존 공개 Site의 정보/정적 기능을 갱신했다. 기존 로컬 알림 구현과 private 상태를 삭제하거나 공개 Site로 옮기지 않았다. 과거 Render 구상은 미승인 보류 자료이며 다음 작업으로 자동 추진하지 않는다.

## 비교 규칙·불확실성

- FIT/PARTIAL은 **금액·기간 공시 비교 상태**이며 정책 PASS나 가입 자격 승인 상태가 아니다. 개인 가입 자격은 모든 상품에서 UNKNOWN.
- PARTIAL은 한도가 작은 상품에 일부 예산을 납입하는 독립 대안이다. 비교표에 선택한3개에 동일 예산을 동시에 배분하는 결과가 아니다.
- 월 저축액과 목돈의 미입력/0원을 구분한다. 목돈만으로 예금 비교도 가능하며 월 예산을 만들어내지 않는다.
- 분기·주간 증액·일납·일 단위 만기는 일반 월 고정 납입으로 환산하지 않는다. 일정/자료 추가 확인으로 남긴다.
- 미확인 상한을 무제한으로 간주하지 않는다. KB Star/하나의 정기예금은 이번 확보 자료에 상한이 확정되지 않아 긍정 비교를 보류한다.

- 공식 검색 색인/공식 문서/이전 검증 스냅샷을 구분한다. 상세 출처는 `PRODUCT_DISCOVERY_SOURCES.md`.
- 실제 상품 만기 계산0개·미승인 지원금 반영0원. 이자를 계산하거나 정부 지원금을 추정하지 않는다.

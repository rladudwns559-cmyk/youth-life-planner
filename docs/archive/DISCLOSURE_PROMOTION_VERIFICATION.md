1. 월 저축 가능 금액·목표 기간·선택적 목돈을 입력하고 ‘내 조건으로 비교’를 누른다.

4. 공시 탭의 연결된14항목에는 ‘내 조건으로 비교 · 상품명’이 나타난다. 누르면 정확한 상품ID로 상세 탭이 열리고 기존 입력·적용 상태를 유지한다. 관련 없는 검색 필터는 해제한다. 선택 상품 제목으로 키보드 초점과 화면을 이동한다.
5. ‘선택 해제하고 전체 보기’로74개 목록으로 돌아간다. 미검증 공시 항목에는 비교 이동 버튼을 붙이지 않는다.

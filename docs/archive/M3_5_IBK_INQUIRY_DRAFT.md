문의 준비 판단: **`IBK_INQUIRY_READY_FOR_USER_REVIEW`**. 날짜별 계산 검증 판단은 **`M3_OFFICIAL_SAVINGS_RULES_VERIFIED_EXAMPLE_MISSING`** 유지입니다.

## 최종 문의문

제목: 대학 프로젝트 검증용 정기적금 날짜별 세전이자 가상 사례 요청

안녕하세요. 대학 프로젝트로 청년의 예산·저축계획을 비교하는 웹서비스를 개발하고 있습니다. IBK기업은행 정기적금 [정액적금]의 계산 규칙을 정확히 이해하고 검산하기 위한 문의이며, 개인 계좌 조회나 상품 가입 상담은 아닙니다. 실제 고객의 계좌정보·거래내역 없이 공개적으로 제공 가능한 가상 사례만 부탁드립니다.

[공식 상품설명서](https://www.ibk.co.kr/fup/customer/form/202609031854581017151883581128.pdf#page=2) 2쪽에서 입금일부터 만기일 전일까지의 예치일수/365로 입금건별 이자를 계산하고 합계에서 원 미만을 절사한다는 안내를 확인했습니다. 추가로 다음 세 가지를 확인하고 싶습니다.

A. 정상 납입·중도해지 없음·납입 지연 없음 조건으로 **12개월·12회 납입의 가상 계산 사례 1건**을 제공받을 수 있을까요? 은행에서 정한 가상 가입일·최초 납입일, 12회 각각의 약정 납입일·실제 유효 입금일·예치일수, 월 납입금액, 약정 연이율, 해당 계약의 만기일과 **은행이 계산한 세전 총이자**가 함께 필요합니다. 월 납입금액과 금리·날짜는 공개 가능한 예시 조건으로 정해주셔도 됩니다. 적용 설명서·약관 기준일도 알려주시면 감사하겠습니다.

B. 각 입금건의 소수 이자를 유지한 뒤 총합에서 원 미만을 절사하나요? 회차별 또는 중간 단계의 절사·반올림, 소수 자릿수나 계산 정밀도 제한이 있다면 공개 가능한 범위에서 알려주시기 바랍니다.

C. 실제 유효 입금일과 약정 납입일이 다르면 예치일수는 어느 날짜부터 계산하나요?

가능하다면 월말 가입 시 납입일, 공휴일 자동이체, 윤년의 실제 일수와 365 분모 적용, 만기이연 조건도 추가 안내 부탁드립니다. 보충 항목을 모두 답변하기 어려우면 A의 날짜별 공식 세전이자 사례와 B·C의 계산 조건을 우선 부탁드립니다.

저희가 미리 계산한 금액을 정답으로 제시하지 않고, 은행에서 제공한 일정과 결과를 별도로 검산하려는 목적입니다. 회신 내용을 교육용 검증 근거로 인용·요약할 수 있는 범위와 출처 표기도 함께 안내해주시면 감사하겠습니다.

## M3.6 후속 상태 — 사용자 발송 완료 보고

사용자가 M3.6 지시문에서 IBK 이메일 발송 완료를 알려줬습니다. 현재 상태는 **이메일 발송 완료 / 공식 회신 대기**(`awaiting_external_evidence`, evidence=사용자 보고)입니다.
이후에는 기존 준비 단계의 미전송/사용자 검토 대기를 현재 상태로 사용하지 않습니다. 에이전트가 직접 접수 완료 화면을 확인한 것은 아니며 발송일·접수번호는 미확인(null)입니다.
회신 원문은 아직 제공되지 않았으므로 답변 내용과 날짜별 공식 기대이자를 생성하지 않습니다. 중복 문의를 보내지 않았습니다. M3.5 판단과 실제 금융상품 계산0개를 유지합니다.


## 2026-10-29 후속 상태 — 이메일 답변 제공 불가 사용자 보고

날짜별 납입 일정과 독립적인 은행 기대 세전이자는 여전히 미확보다. `M3_OFFICIAL_SAVINGS_RULES_VERIFIED_EXAMPLE_MISSING`, 실제 금융상품 만기 계산 0개, 미검증 실제 지원금 반영 0원을 유지한다. 가상 계산을 공식 정답으로 변경하지 않는다.

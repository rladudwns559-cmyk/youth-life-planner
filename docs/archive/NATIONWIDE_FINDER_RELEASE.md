## 사용 흐름

지역·나이·고용·월세 조건을 선택하고 **내 조건으로 찾기**를 누르면 결과 창이 열린다. 공식 모집 상태와 입력 조건을 보여 주고 사업 3개까지 담아 비교한다. 결과 창의 적금·예금 탭은 월 납입액과 목돈을 따로 받아 기존 Python 비교표를 조회한다. 닫기나 Esc로 입력 화면에 돌아갈 수 있다.

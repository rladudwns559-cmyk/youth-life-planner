## 추천에 실제로 반영되는 방식

금액·기간이 맞는 전액 납입 후보를 우선하고, 같은 종류·기간에서 확인한 기본금리순으로 TOP3를 보여준다. 우대조건을 자동 충족했다고 보거나 만기금액으로 순위를 매기지 않는다. 일부 예산 배정은 전체 예산 적합성과 구분한다.

11월3일 공개 화면에 월30만원/12개월 입력 시 적금 TOP3는 부림 톡톡 정기적금 기본 연4.20%, 모아 e-모아 정기적금4.00%, 카카오뱅크 자유적금3.85%였다. 이는 검토 시점의 기본금리 비교이며 가입자격이나 최종 수익 보장이 아니다.

공식 상한이 불명확하면 무제한으로 만들지 않고 UNKNOWN/MISSING으로 남겼다. 창구·모바일 자료가 실제로 일치한 e-모아만 보류를 해제했다. IBK 일부 금리 충돌·KB CD연동/표 불일치·우리 일부 미확인 최소금액·특수 납입일정은 정보 비교만 제공한다. 판매 종료를 확인한 KB직장인우대는 추가하지 않았다.

공개5개 합성 입력(월30만원12개월,동일+목돈1천만원,월300만원12개월,월30만원36개월,월0원)을 Python 기대 추천ID와 대조했다. 상세는 public-profiles.json이다.

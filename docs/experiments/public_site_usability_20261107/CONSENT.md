# 참가 안내와 동의 (진행자가 읽어 주는 글)

이 점검은 대학 프로젝트로 만든 "청년 경제생활" 웹사이트가 처음 쓰는 사람에게 이해하기 쉬운지 알아보려는 것입니다. 사이트를 평가하는 것이지 참가자를 평가하는 것이 아닙니다. 틀려도 괜찮고, 막히는 곳이 바로 저희가 고쳐야 할 곳입니다.

- 실제 지원금 신청이나 금융상품 가입을 하지 않습니다. 과제는 가상의 조건으로 진행합니다.
- 실제 이름·연락처·나이·소득·월세·계좌번호는 묻지 않고 적지 않습니다. 자유 의견에도 개인정보를 말하지 말아 주세요.
- 진행자가 적는 것: 가명 번호(P01~P03), 과제별 성공 여부와 걸린 시간, 막힌 지점, 1~5점 평가 3개(선택), 자유 의견(선택), 사용 기기 종류.
- 예상 시간은 15~20분입니다.
- 참여는 자유입니다. 거절하거나 언제든 중단할 수 있고, 답하기 싫은 질문은 넘어가도 됩니다. 끝난 뒤 철회하려면 진행자에게 말해 주세요. 해당 기록을 삭제합니다.
- 기록은 진행자의 비공개 폴더에만 보관하고 공개 저장소나 외부 AI 서비스에 올리지 않습니다. 발표에는 "3명 중 몇 명" 같은 집계와 관찰만 사용합니다. 진행자가 참가자를 아는 사이일 수 있어 완전한 익명은 보장하지 못합니다.
- 기록은 대회 종료 후 30일 안에 삭제합니다.

동의하시면 "동의합니다"라고 직접 말씀해 주세요. 진행자는 그 말을 들은 뒤에만 시작합니다.

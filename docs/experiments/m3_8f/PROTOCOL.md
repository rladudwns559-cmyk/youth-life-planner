```powershell
python -B -m tools.explanation_study --key docs/experiments/m3_8f/private/study_key.json --kind real --sessions '<비공개 응답 폴더>' --output '<새 분석 폴더>'
```

기존 결과를 덮어쓰지 않는다. 합성 집계는 `--kind synthetic` 및 SYN### ID, 별도 폴더·summary_synthetic 파일을 사용한다. 실제0명 표를 합성 점수로 채우지 않는다.

## 최종 결정을 위한 회신/추가 증거

현재 사람 평가0명이라 우수성 결론 없음. **다음 최소 작업 하나는 T08의 실제 B 문장 증거 확보 재검토**다. 우선 두 TIMEOUT의 실행 조건·기존 로그를 검토하고, 추가 실행은 새 승인 범위에서만 한다. 검증기·6/8/12초·기존 제품 코드를 바꾸거나 후보를 직접 선택해 실제 모델 출력으로 만들지 않는다. 이 근거가 확보돼8과제 자료를 검증한 뒤에야 참가자 모집/동의5명을 진행할 수 있다.

# 설명 이해도 평가 안내 · P01

이 폴더는 예정 배정 자료입니다. 참여·동의·응답이 완료됐다는 뜻이 아닙니다.

진행자가 index.html을 브라우저로 열고 ‘파일 선택’에서 sessions/P01.json을 선택한 뒤, 참여 안내 화면에서 참가자에게 인계합니다. 다른 참가자 파일이나 실험자 정답표는 제공하지 않습니다. 평가 전에 ‘합성 자료로 도구 미리보기’를 사용하지 않습니다.

예상15~25분(실제 소요시간 미측정), 합성 인물의8개 과제를 읽고 답합니다. Python 정형 설명과 로컬 AI가 허용 후보에서 선택한 문장이 포함되며 어느 방식이 더 좋은지는 아직 모릅니다. 실제 금융상담이나 지원금 신청이 아닙니다.

안내를 읽고 자발적으로 동의한 경우만 시작하세요. 이름·연락처·실제 소득·월세·계좌번호는 입력하지 않습니다. 모르면 ‘모르겠다’, 답하지 않으려면 빈칸으로 남길 수 있습니다. 점수나 의견은 선택이며 언제든 중단할 수 있습니다. 정답 제출 후 이전 과제로 돌아가지 않습니다.

모든 주 과제 뒤 선택적으로 두 설명을 비교합니다. 마지막 ‘기록 JSON 내려받기’는 이 기기에 파일을 저장할 뿐 외부 전송을 하지 않습니다. 저장 전 철회하면 저장하지 않고 닫으세요. 저장 후 철회는 담당자에게 P01로 요청하세요. 이름/연락처는 이 기록에 넣지 마세요.

원자료는 담당자만 비공개 로컬 보관하며 외부 LLM·공개 노트에 보내지 않습니다. 공개 보고는 집계만 사용하고 최종 보고 후30일 이내 원자료를 수동 삭제합니다. 자세한 안내는 시작 화면에서 다시 확인하세요. 저장하지 않고 닫으면 응답은 사라집니다.

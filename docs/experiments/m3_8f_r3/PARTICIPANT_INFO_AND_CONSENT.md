# 참가자 안내와 기록 동의

이 평가는 합성 경제생활 화면의 설명이 얼마나 이해하기 쉬운지 알아보려는 대학 프로젝트입니다. 실제 지원금 자격이나 금융상품을 추천·가입하는 절차가 아닙니다.

Python 정형 설명과 로컬 AI가 허용 후보 중 선택한 설명이 포함됩니다. 어느 방식이 더 좋은지는 아직 확인되지 않았습니다. 개별 과제의 설명 방식은 먼저 알려드리지 않습니다. 같은 계산값과 정책 상태를 바탕으로8개 과제를 읽고 답합니다. 주 과제를 마친 뒤 선택적으로 두 설명을 비교합니다. 예상15~25분은 실측 전 추정입니다.

기록 항목은 가명 참가자ID, 동의/중단 여부, 과제 답, 읽기·응답 소요시간, 화면 이탈 여부, 이해 용이성·유용성·신뢰감1~5점, 선택적 선호와 자유 의견입니다. 실제 이름·연락처·소득·월세·계좌번호는 기록하지 않습니다. 의견에도 개인정보를 적지 마세요.

참여는 자발적입니다. 거절하거나 언제든 중단할 수 있습니다. 모르면 ‘모르겠다’, 답하고 싶지 않으면 빈칸으로 남길 수 있습니다. 평점과 의견도 선택입니다. 저장 전 철회하면 파일을 내려받지 않고 닫으세요. 저장 후 철회하려면 담당자에게 참가자ID로 알려주세요. 담당자가 해당 기록을 찾아 철회 처리를 안내합니다. 진행자가 참가자를 직접 아는 경우가 있어 완전한 익명성을 보장하지 않습니다.

이 화면은 응답을 외부 서버로 자동 전송하거나 브라우저에 영구 저장하지 않습니다. 마지막에 선택하면 이 기기에 JSON 파일을 내려받습니다. 담당자는 제공에 동의한 원자료를 자신의 비공개 로컬 폴더에 보관하고 외부 LLM·공개 저장소·Obsidian 공개 노트에 보내지 않습니다. 공개 보고에는 집계만 사용하며 개인 의견 원문 공개는 기본적으로 하지 않습니다. 원자료는 최종 보고 후30일 이내 담당자가 수동 삭제합니다.

안내를 이해했고 자발적으로 참여·기록에 동의하면 화면의 체크를 직접 선택하고 시작하세요. 동의하지 않으면 시작하지 않아도 됩니다. 담당자는 실제 동의 여부를 확인한 뒤에만 진행합니다. 이 안내문이나 예정 참가자ID만으로 동의가 완료된 것으로 처리하지 않습니다.

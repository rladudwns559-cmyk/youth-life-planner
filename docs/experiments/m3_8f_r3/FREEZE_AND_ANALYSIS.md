# 동결 확인과 실제 응답 분석 절차

기준은 **m38f-study-v2-r2**다. R3는 기존 실험을 실행할 준비만 하며 설명·정답·채점·배정·제품 코드를 바꾸지 않는다. 실제 응답 없음이 확인돼 지금은 사람 통계 결과를 만들지 않았다.

## 평가 전·후 동결 확인

`freeze_manifest.json`에 study_v2 전체와 원본 실패2건/R2 원문/집계 코드 등43파일의 SHA256·크기·mtime를 기록했다. 8과제는 T01/EX01, T02/EX02, T03/EX04, T04/EX07, T05/EX09, T06/EX11, T07/EX12, T08/FU01이다. 정형A/실제모델B/Python Facts/정답/보기/출처는 `facilitator/study_key.json`의 원본 바이트 복사본에 있다.

평가 전후 원본과 배포 패킷의 해시가 동결본과 같은지 확인한다. 개별 패킷의 index.html과P세션JSON은 원본과 byte-identical이다. 참여자가 답을 낸 뒤 설명/정답을 고쳐 채점하지 않는다. 변경이 필요하면 중단하고 원본·변경 이유·새 버전·대상자를 구분한다. 기존v1과T08실패2건/R2원문은 그대로 보존한다.

## 실제 응답 인수 점검

1. 담당자가 실제 동의·제공 의사를 확인한 JSON만 비공개 raw_sessions에 복사한다. 계획 세션JSON·QA_SYN001·코드시험용 자료는 이 폴더에 넣지 않는다.
2. 원본 파일명/크기/SHA256과 제공받은 상태를 비공개 진행 기록에 남긴다. 불필요한 이름·연락처·실제 경제정보는 수집하지 않는다. UI가 내보낸 답과 의견을 임의 수정하지 않는다.
3. 같은 사람의 중복 파일이 있으면 원본을 모두 보존하고 담당자가 어떤 제공본을 분석할지 확인한다. 파일을 합치거나 최신 파일을 자동 선택하지 않는다. 진행본/완료본/철회본을 실제 상태에 맞게 구분한다.
4. participant_id·allocation_slot·consented·session_status와 과제ID/order를 점검한다. 완료 상태에8과제가 없거나 중복ID/같은과제중복/틀린보기/잘못된시간/실제-합성혼합이 있으면 기존 검증 도구는 거부한다. 오류를 정답으로 채워 넣지 않는다.
5. 결측·중단·철회·외부 개입은 사실대로 기록한다. 실제 미응답은 빈칸, 누락 시간은 결측이다. 임의0초/추정시간/가상 평점으로 대체하지 않는다. 철회 원자료 삭제는 당사자 의사와 프로토콜에 따라 담당자가 처리하며 자동 삭제하지 않는다.

## 기존 집계 도구 사용

실제 파일이 확보된 후에만 아래 명령을 사용한다. 경로는 로컬 예시이며 출력은 새 폴더로 지정한다. 세션JSON과 CSV의 두 경로를 한꺼번에 입력하지 않는다. 별도 서버·LLM·API키가 필요 없다.

```powershell
Set-Location -LiteralPath '<USER_HOME>\Documents\ChatGPT\ai+x'
& '.\.venv\Scripts\python.exe' -B -m tools.explanation_study --key 'docs/experiments/m3_8f_r2/study_v2/private/study_key.json' --kind real --sessions '<USER_HOME>\Documents\ChatGPT\AI+X채팅\study-responses\m3.8f-r3\raw_sessions' --output '<USER_HOME>\Documents\ChatGPT\AI+X채팅\study-responses\m3.8f-r3\analysis_runs\run_001'
```

이번 R3에서 이 명령으로 실제0명 통계표를 새로 생성하지 않았다. 기존 관련 테스트123개(임시·합성 fixture 포함)와 패킷/배정/동결 구조 검증만 수행한다. 소스와기존검증/채점코드를수정하지 않는다. 전체 Backend12315/1skip/1warning·Frontend115/build는 R2의 직전 전체 실측이다.

## 분석에서 구분할 것

- 기존 assigned 정답률과 observed 정답률, 완료율, DK/결측을 함께 보고한다. 원자료 빈칸은 유지한다. 주 assigned 지표에서만 미응답 비득점/고정 분모를 적용한다.
- 평균·중앙 시간은 조건별 관측 n을 표시하고 탭 이탈 없는 보조 결과도 함께 본다. 단위는 원자료ms→기존 집계seconds다. 평점 시간과 섞지 않는다.
- UNKNOWN 이해도는 동결 키의 `category=unknown`인 T03/q3와T04/q3를 기준으로, 기존 정답 집합과 동일하게 채점한다. `observed_wrong_by_category.unknown`은 오답 수이며 정답률 자체가 아니다. 실제 자료 확보 후 기존 `validate`의 정제 응답과 고정 키로 정답/응답/할당 분모·DK·결측을 따로 산출해 검산한다. 숫자를 보지 않고 지표를 갈아 끼우지 않는다. 지금은 모두 미측정이다.
- 정책 표시·금액·원인·확인사항은 동결 key의 각 질문/범주에 대응시킨다. UNKNOWN 오답과 정책 전체 오답을 같은 지표라고 부르지 않는다.
- 자유 의견 원문은 담당자가 로컬에서 읽고 보존한다. 공개 보고에는 식별정보 없는 요약만 사용한다. 외부 LLM에 원문을 보내지 않는다. 특정 의견이 없으면 만들어 채우지 않는다.
- 분석 단위는 사람이다. 개인별A/B 정답률과 B−A 차이를 기본 비교로 보고,40과제/160문항을독립된40명/160명이라고하지않는다. 단5명은 탐색평가이며 편의표본/문항난이도/순서/반복정책학습/문장길이/중단편향의한계를공개한다.
- 기존 도구는 비어 있는 실제 자료에READY_PENDING, 자료가 있으면PARTIAL을 기본 반환하고 사람 완료/우수성을 자동 승인하지 않는다. R3 완료 판정은 동의·실제 참여/기록 완결성·조건별 분석·한계를 담당자가 검토해 정한다.
- 사전 목표80%/이해도4점/중대한모순0은 성과가 아니다. 사용자오답은 모델모순과 별도다. AI와 정형이 비슷하거나B가낮으면그대로보고한다.
